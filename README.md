# AI Agents — The Complete Engineering Reference / Docs Bundler

> A structured, docs-first learning path for AI Agents — from LLM fundamentals to production deployment. Every chapter follows the same rigorous template: concept → why it matters → mental model → diagrams → official docs → papers → code → pitfalls → production practices → security → exercises → interview questions.

## Why this repo exists

Most "awesome-agents" lists are link dumps. This is different: every chapter is a self-contained lesson that teaches the concept properly, then points you to primary sources (official docs and papers) rather than paraphrasing them badly. Read it top to bottom as a course, or jump to any chapter as a reference.

## How chapters are structured

Every chapter in `/docs` follows this template, in this order:

1. Plain-language explanation
2. Why it matters
3. Mental model / analogy
4. Diagram(s) (Mermaid)
5. Official documentation (linked first)
6. High-quality secondary resources
7. Seminal papers
8. Implementation example(s)
9. Common mistakes & debugging
10. Production best practices
11. Security considerations
12. Exercises & project ideas
13. Interview questions
14. Related concepts & further reading
